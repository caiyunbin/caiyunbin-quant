👥 用户账号操作 (CLI 速查)

        

            
生成 N 个用户账号 (默认 7 天)

                python v26_production/manage_accounts.py gen 10 --days 7

            
批量生成 50 个 (7/30/90/180/365 各 10)

                python v26_production/manage_accounts.py gen-batch

            
续期账号

                python v26_production/manage_accounts.py extend <user> --days 30

            
让所有操作生效 (推 GitHub)

                bash v26_production/automation/run_update_site.sh
