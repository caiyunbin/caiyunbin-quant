🏦 板块轮动 (ETF) 模块可见性

当前对用户:

⚠ 静态站不能直接 toggle. 切换可见性需要在本机执行以下命令并 push:

# 设置为对用户可见
python v26_production/manage_accounts.py set-etf-visible 1
# 设置为隐藏
python v26_production/manage_accounts.py set-etf-visible 0
# 让改动生效
bash v26_production/automation/run_update_site.sh

🔑 修改管理员密码

⚠ 静态站不能直接改密码. 在本机执行 (替换 NEW_PWD 为新密码, 建议 12 位以上字母数字):

python v26_production/manage_accounts.py admin-change-pwd NEW_PWD
bash v26_production/automation/run_update_site.sh

👥 用户账号操作 (CLI 提示)

生成 N 个新账号 (默认 7 天)
python v26_production/manage_accounts.py gen 10 --days 7
批量生成 50 个 (7/30/90/180/365 各 10)
python v26_production/manage_accounts.py gen-batch
撤销账号 (实时生效)
python v26_production/manage_accounts.py revoke u2hermd7
续期账号
python v26_production/manage_accounts.py extend u2hermd7 --days 30
让所有改动生效 (推送到 GitHub)
bash v26_production/automation/run_update_site.sh
